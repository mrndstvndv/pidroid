Extensions

Every extensions/*.ts file default-exports one extension and is hot-swapped on reload — no restart, sessions keep running. The switch on each row turns that extension off or on: flipping it reloads right away, so a disabled extension drops its tools, prompt sections and hooks from the next turn on. Files starting with an underscore are skipped by the loader and have no switch.
